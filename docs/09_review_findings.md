# Senior Design Review & Audit Findings

This document records the protocol-compliance, CDC/reset hygiene, and FPGA/ASIC synthesis audit of the existing SystemVerilog IP library (`common/rtl/*`, `interconnect/*`, `ips/01..14`, and `ips/17_mini_tpu`), the fixes applied, the new AXI4-Stream and AXI4 utility infrastructure added to close library gaps, and the remaining known limitations.

## 1. Review Scope & Verification Methodology

- **Standards audited against**:
  - AMBA AXI4 / AXI4-Lite (ARM IHI 0022E): `AxLEN`/`AxSIZE`/`AxBURST` legality, narrow & unaligned transfers, `WSTRB`, `WLAST`/`RLAST`, 4KB boundary rules, per-ID in-order response ordering, handshake hold-stability (`VALID && !READY`), exclusive-access (`EXOKAY`) policy.
  - Wishbone B4 (Classic + Pipelined / Registered Feedback): `CYC`/`STB`/`STALL`/`ACK`/`ERR`/`RTY`, `CTI`/`BTE`, hold-fields-under-stall (Rule 3.60), classic hold-`STB`-until-`ACK`, in-order pipelined responses across slaves.
  - TileLink 1.8 (TL-UL / TL-UH): `a_opcode`/`a_param`/`a_size`/`a_address`/`a_mask` legality, alignment, `a_corrupt`/`d_denied`/`d_corrupt` semantics, multi-beat Channel A/D message atomicity, hold-stability under backpressure.
  - CDC, reset, and FPGA/ASIC synthesis hygiene: Gray-pointer async FIFOs, reset synchronization, BRAM/SRAM inference (clock-only RAM writes), 2-FF input synchronizers on external pins, zero combinational loops, zero latches, explicit `automatic` locals.
- **Verification suites run (Verilator 5.054, `-Wall` repo flags, zero warnings, no new `-Wno-*` or `lint_off`)**:
  - [`tb/tb_audit_regress.sv`](file:///Users/tianrui6641/tians_ip_collection/tb/tb_audit_regress.sv) (`tb_audit_regress`): 21 directed and randomized regression tests (`AR-01`..`AR-22`) with independent behavioral models and scoreboards; bugs were reproduced pre-fix and verified post-fix across multiple seeds (`+seed=1, 2, 7`).
  - [`tb/tb_axis_utils.sv`](file:///Users/tianrui6641/tians_ip_collection/tb/tb_axis_utils.sv) (`tb_axis_utils`): 39 DUT configurations covering all 8 new AXI4-Stream modules (~33.9k frames/ops per seed, seeds `1` and `42`).
  - Independent `vkit` protocol-checked random fabric regressions: `tb_vkit_wb_xbar_rand`, `tb_vkit_tl_xbar_rand`, `tb_vkit_smart_switch_rand`, `tb_vkit_axi_xbar_rand`, `tb_vkit_csr_selftest` (seeds `1..3`, 100% coverage bins, 0 protocol violations).
  - Pre-existing and APB4 regressions: `tb_interconnect_bridges`, `tb_crossbars_smart_switch`, `tb_apb_peripherals` (`txdata_err_quirk=0`), `tb_mini_tpu`, and all modified peripheral TBs (`tb_uart_usart`, `tb_spi`, `tb_xspi_xip`, `tb_hyperram_ctrl`, `tb_nvpsram_ctrl`, `tb_gpio`, `tb_ledc`, `tb_eth_mac`).

## 5. Remaining Known Limitations & FPGA / Tape-Out Notes

1. **AXI4 Exclusive Accesses (`AxLOCK` / `EXOKAY`)**: `bus_pkg::axi4_m2s_t` intentionally omits `awlock`/`arlock` and `awcache`/`arcache`. No crossbar or slave implements an exclusive access monitor; `EXOKAY` is never generated by library slaves and is mapped to `OKAY` at AXI4-Lite boundaries.
2. **AXI4 Crossbar Outstanding Depth**: `axi4_xbar` supports 1 outstanding write and 1 outstanding read per master (in-order per master) without a multi-ID reorder buffer. This trivially satisfies per-ID ordering while keeping area low; systems requiring multiple outstanding IDs to narrow-ID out-of-order targets should insert `axi4_id_remap`.
3. **Smart Switch Watchdog `abort_i`**: When a downstream slave hangs past `TIMEOUT_CYCLES`, `smart_switch_interconnect` asserts `abort_i` into `mem_to_{axi4,tl_uh,wb}_master` so the rest of the fabric does not deadlock. On AXI4/TileLink, aborting an active stalled transaction intentionally drops `*VALID` mid-handshake on the hung port; the hung target requires a reset before safe reuse.
4. **Wishbone `LOCK` Signal**: `bus_pkg::wb_m2s_t` does not include `LOCK_O`. Multi-master atomic RMW operations should use TileLink TL-UH `ArithmeticData`/`LogicalData` or software synchronization.
5. **TileLink Sub-Word AMOs**: `tl_ul_to_csr` supports 32-bit word AMOs (`a_size <= 2`). For sub-word `a_size < 2`, `ArithmeticData` MIN/MAX comparisons operate on the full 32-bit word before applying `a_mask` on the writeback.
6. **Write-Combining Posted Errors**: `width_upsizer_32to64` with `WRITE_COMBINE = 1` acknowledges the buffered low word immediately (`narrow_ready_o = 1`); a downstream `wide_err_i` observed during a subsequent flush cannot be retrofitted onto the already-completed low write.
7. **`async_fifo` Reset Coupling & `wfull_o` Reset Polarity**: `common/rtl/async_fifo.sv` requires `wrst_ni` and `rrst_ni` to be asserted simultaneously (with per-domain synchronous deassertion via external reset synchronizers). `wfull_o` resets to `1'b0` for backward compatibility with existing consumers, so callers must hold `wpush_i = 0` while `wrst_ni = 0`.
8. **Crossbar Timing Closure**: With `PIPE_MASTER = 0` / `PIPE_SLAVE = 0`, all three crossbars (`axi4_xbar`, `wb_xbar`, `tl_xbar`) contain combinational arbitration and mux paths between master and slave ports. For real FPGA/ASIC timing closure at `>= 4x4`, set `PIPE_MASTER = 1` and `PIPE_SLAVE = 1`.
9. **Peripheral Implementation Scope (`ips/01..14`, `17`)**:
   - `xspi_xip_core`: SDR only (`CTRL[2]` DDR mode and `xspi_dqs_i` are unimplemented).
   - `nvpsram_ctrl_core`: QSPI mode transfers 32-bit words without sparse `wstrb` byte-run splitting; default `acc_div = 1` is tuned for simulation speed and must be programmed higher via `CTRL[15:8]` for physical PSRAM timing.
   - `ext_mem_ctrl_core` (SDRAM/SRAM/NVSRAM): Power-up 100us delay and full per-bank row-active/precharge (`tRAS`/`tRC`/`tWR`) tracking are simplified; physical SDRAM bring-up requires conservative timing-register settings and board-level PHY calibration.
   - `eth_mac_1g_core`: RX async FIFO drains at 1 sample per `clk_i` cycle, requiring `f(clk_i) >= f(phy_rx_clk_i)`.
   - `mini_tpu_core`: Scratchpad writes (`imem_q`, `sbuf_q`, `abuf_q`, `wbuf_q`, `obuf_q`) use a clock-only `always_ff`, which is RAM-friendly, but reads are combinational (`always_comb`) and writes use `apply_wstrb(...)` read-modify-write, which infers LUTRAM/registers on FPGA; high-density BRAM/SRAM tape-out targets should add a 1-cycle registered read stage and explicit per-byte write-enable lanes.
